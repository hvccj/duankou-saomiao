# 端口扫描工具项目展示优化设计

## 目标

将当前可运行的 PyQt5 本机 TCP 端口扫描工具，整理为适合 GitHub 展示的完整项目。重点提升项目可理解性、可运行性说明、技术要点表达和视觉呈现，不为了“包装”进行高风险架构重写。

## 项目定位

项目定位为“基于 PyQt5 的本机 TCP 端口扫描与可视化分析工具”，突出以下能力：

- 端口范围解析与输入校验
- 基于 `QThread` 与工作线程的并发扫描
- 扫描进度与结果实时更新
- 开放端口筛选和完整结果切换
- 系统与主机信息展示
- 扫描结果本地保存
- 面向合规测试和本机排障的安全边界

## 交付内容

### 1. README.md

README 包含：

- 项目简介和适用场景
- 功能矩阵
- 界面截图
- 技术栈和核心设计
- 扫描流程与线程模型说明
- Windows 环境安装和运行步骤
- PyInstaller 构建说明
- 性能与限制说明
- 隐私、安全和合规边界
- 项目技术要点和设计取舍说明

### 2. 文档

新增 `docs/` 文档：

- 架构/数据流图，说明 GUI、扫描线程、任务队列和结果表之间的关系
- 技术说明，介绍项目难点、取舍、并发模型和可改进方向

### 3. 真实截图

运行软件并保存经过隐私检查的真实界面截图，用于 README 展示。截图不得包含真实用户名、内部 IP、设备名或其他个人信息；必要时使用本机测试环境或打码后的画面。

### 4. 低风险源码整理

只进行与可靠性和可读性直接相关的改动：

- 补充必要的模块、类和关键流程说明
- 将裸异常处理改为明确的输入校验或受控异常处理
- 改善无效端口输入的提示
- 保持现有扫描、筛选、保存和停止行为不变

## 不在本次范围内

- 不新增远程扫描、批量主机探测或外部数据上传
- 不引入数据库、云服务或账号系统
- 不将构建产物、虚拟环境、字节码或本地路径提交到仓库
- 不进行为了拆分文件而拆分文件的大规模重构

## 验证标准

- README 中的安装、运行和构建命令与仓库实际文件一致
- Python 源码通过语法编译检查
- 关键输入场景可验证：默认端口、单端口、端口区间、非法输入
- Git 暂存内容不包含凭据、个人绝对路径、构建产物或缓存
- 推送后 GitHub 首页能够直接展示项目简介、截图、运行方式和技术要点

## 提交策略

设计文档作为独立提交保存；实施完成后使用一个或多个语义清晰的增量提交推送到 `main` 分支。
